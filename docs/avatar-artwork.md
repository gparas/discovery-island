# Profile avatar artwork

Asset: `public/assets/island-avatars.png` — single 3 × 2 transparent sprite atlas, generated using the built-in ImageGen tool. The interface displays each cell with CSS background positioning. The exact generation prompt is also embedded in the PNG.

## Generation prompt

Create one production UI sprite atlas for a Greek children's discovery island game: six distinct friendly illustrated profile avatars in an EXACT 3-column by 2-row evenly spaced grid on transparent background, landscape canvas aspect ratio 3:2. Every cell is square, with its object centered and occupying about 65% of the cell, generous transparent margins; no overlap. Reading order: small Mediterranean sailboat with cream sail and coral stripe; coral-and-cream lighthouse; pale coral seashell; fresh green leaf; warm golden sun with simple rays and no face; small turquoise fish. Style: polished charming children's game illustration, soft dimensional painted shading, rounded clean contours, warm Mediterranean daylight; coherent cream teal navy coral yellow green palette. These are six isolated objects, no circular badges, no backplates, no scenery, no ground shadows, no letters or numbers, no characters, no UI. Exact centered regular grid is essential for using this as a CSS sprite atlas. Each object must be recognizable at 72 pixels. This is a single reusable sprite atlas asset, not a screenshot.
